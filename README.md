# Eco Cylon Mushrooms

A React + Vite website for a mushroom business, featuring:
- Home and hero section
- About us story
- Product highlights
- Health and sustainability benefits
- Gallery and contact section

Run locally:
1. npm install
2. npm run dev

## Project Overview

Ceylon Mushroom is a responsive web application developed to showcase and promote fresh mushroom products. The website provides an intuitive user experience that allows customers to browse available products, add items to a shopping cart, and place orders conveniently through an order form or WhatsApp integration.

This project was developed as a frontend-based ordering platform without a backend system, focusing on user-friendly design, product presentation, and seamless customer interaction.

## Features

- Browse a variety of mushroom products with detailed information
- Add and manage products in a shopping cart
- Simple order placement form for customer inquiries and orders
- Direct WhatsApp integration for quick communication and order confirmation
- Responsive design compatible with desktop, tablet, and mobile devices
- Modern and intuitive user interface
- Fast and lightweight frontend implementation

## Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
